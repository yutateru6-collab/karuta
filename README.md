# 限界カルタ

現代人の日常の「もう限界」を、白黒漫画＋一句でめくるモバイル向けWebアプリです。

## v0.1

- 札を左右スワイプして閲覧
- 札をタップすると3Dで裏返り、元の長い解説を表示
- 「今日の限界」で1〜3枚選択
- 選んだ札から縦長の「本日の限界届」PNGを生成
- 全札一覧・カテゴリ絞り込み
- PWA / オフライン対応
- iPhoneの全画面表示を意識したレスポンシブUI

## カードのデザインルール

- 外側の白い余白なし。画面いっぱいにカードを見せる
- 太い黒縁、オフホワイト紙、白黒漫画ベース
- 赤は金額・記号・時計など一部だけに使う
- 縦書きの一句、右上に丸囲みの頭文字
- 人物は男女・年代を札ごとに変える
- 表：一句＋漫画 / 裏：元の長い解説

`assets/` の画像を追加し、`cards.js` の `image` を指定すると画像版の札になります。画像がない札は同じ黒白赤のルールで自動フォールバック表示します。

依存関係のない静的サイトです。Cloudflare Pages / GitHub Pages 等でそのまま公開できます。
